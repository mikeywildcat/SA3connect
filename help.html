What is SA3 NMEA Relay?

SA3 NMEA Relay bridges the Sailaway 3 sailing simulator's built-in NMEA gateway to real navigation software such as OpenCPN or qtVlm. Sailaway outputs NMEA 0183 sentences over a local TCP connection; this app receives them, applies a set of corrections to make the data compatible with standard chart plotters, and re-broadcasts the corrected stream over a second TCP port that your navigation app connects to.

Receive from Sailaway

Connects to the Sailaway NMEA gateway (default 127.0.0.1:10110) and reads the live NMEA stream.

Correct & Filter

Fixes non-standard sentences and removes your own vessel from the AIS feed so other traffic remains visible.

Re-broadcast via TCP Relay

Serves the corrected stream on a configurable port (default 10111) that OpenCPN or qtVlm connects to as an NMEA source.

Runs in the Background

Lives in the macOS menu bar or Windows system tray, relaying data silently while you sail.

Requirements

  • Sailaway 3 with the NMEA Gateway enabled in its settings
  • macOS 11 or later  ·  Windows 10 or later
  • Navigation software that accepts a TCP NMEA source (OpenCPN, qtVlm, etc.)
Note SA3 NMEA Relay, Sailaway 3, and your navigation app all run on the same computer. The relay listens on 0.0.0.0 so chart plotters on other devices on the same local network can also connect.

First Use – Step by Step

  1. Choose your language
    On the very first launch a language selector appears. Choose English, Français, Deutsch or Nederlands and click OK. You can change language at any time from the selector at the bottom of the left panel.
  2. Enable the NMEA Gateway in Sailaway 3
    In Sailaway, go to Settings → NMEA Gateway and make sure it is switched on. Note the host and port (usually 127.0.0.1 and 10110).
  3. Enter the Sailaway connection details
    In the Connection tab, confirm the host (127.0.0.1) and port (10110) match what Sailaway is configured to use.
  4. Click Connect
    Press the Connect button. The status bar at the bottom will turn green and show the connected address once the link is established. NMEA sentences will begin scrolling in the log window on the right.
  5. Start the TCP Relay
    Switch to the TCP Relay tab. The relay host is preset to 0.0.0.0 (accepts connections from any device on your network) and the port defaults to 10111. Click Start Relay. The status line will confirm how many clients are connected.
  6. Connect your navigation software
    In OpenCPN or qtVlm, add a new TCP connection pointing to 127.0.0.1 (or your computer's local IP from another device) on port 10111. Your boat position, heading, wind, and AIS traffic will now appear on the chart.
  7. (Optional) Enable Auto Connect & Auto Relay
    Toggle Auto Connect in the Connection tab and Auto Relay in the TCP Relay tab. Next time you start the app (or at login if Start at Login is on) everything connects automatically — no interaction required.

Connection Tab

Host & Port

Enter the IP address and port of the Sailaway NMEA Gateway. The default 127.0.0.1:10110 works for a local installation. Previous successful addresses are saved in the dropdown history.

Connect / Disconnect

Connect opens the TCP socket to Sailaway. While connecting, the status bar shows Connecting… in yellow. On success it turns green. On failure the error is shown in red.

Disconnect closes the socket cleanly. The relay server continues running and serving its existing clients.

Auto Connect

When enabled, the app automatically tries to connect using the last saved host and port every time it starts. If Sailaway is not yet running it will silently retry every 10 seconds until the connection succeeds — useful when combined with Start at Login.

Tip If the connection drops unexpectedly (Sailaway closed, network hiccup) a pop-up notification will appear asking you to check Sailaway and reconnect manually.

TCP Relay Tab

Relay Host & Port

0.0.0.0 makes the relay accessible from any device on your local network. Change to 127.0.0.1 to restrict it to the local machine only. The default port is 10111.

Start / Stop Relay

Start Relay opens the listening server. Multiple navigation apps can connect simultaneously — the client count is shown next to the button.

Auto Relay

Mirrors the Auto Connect behaviour: the relay server starts automatically on launch using the last saved host and port.

Note The relay server runs independently of the Sailaway connection. You can start it before connecting to Sailaway; it will simply have no data to send until the connection is established.

NMEA Corrections Applied

Sailaway outputs several proprietary or non-standard sentences. SA3 NMEA Relay rewrites them into standard NMEA 0183 equivalents before passing them to your navigation software.

Input sentence Output sentence Description
$SLCLI $IIXDR,A,…,D,ROLL Sailaway heel angle → standard XDR transducer sentence. Sign is inverted to match convention.
$RIRSA $IIRSA Sailaway rudder angle → standard RSA sentence with talker ID corrected to II.
$WIMWV $WIMWV (corrected) Wind angle values greater than 180° are rewritten as negative (signed ±180°) for compatibility with OpenCPN.
AIS VDM sentences (dropped) AIS position reports for your own boat are removed from the stream so that your vessel does not appear as a separate AIS target in your navigation software.
Tip All other NMEA sentences (GPS position, SOG, COG, depth, heading, etc.) are passed through unchanged with their checksums intact.

Menu Bar & System Tray

SA3 NMEA Relay lives in the macOS menu bar or the Windows system tray. Closing the main window hides it rather than quitting — the relay keeps running in the background.

Tray menu options

  • Hide / Show – toggles the main window
  • Menu Bar / Tray Only – when checked, the Dock icon (macOS) is permanently hidden and the window starts hidden on every launch. The tray icon is then the only way to access the app.
  • Start at Login – see below
  • Help – opens this manual
  • Quit – exits the app completely

Notifications

A system notification appears shortly after launch confirming the app is running, and again each time a connection to Sailaway is successfully established.

Start at Login

Enable Start at Login from the tray menu to have SA3 NMEA Relay launch automatically when you log in to your computer.

Combined with Auto Connect, Auto Relay, and Menu Bar / Tray Only mode, the full hands-free workflow is:

  1. Log in to your computer
    SA3 NMEA Relay launches automatically and hides to the menu bar / tray.
  2. Start Sailaway 3
    The relay detects the NMEA gateway and connects automatically (retrying every 10 s if needed).
  3. Open OpenCPN or qtVlm
    Your navigation software connects to the relay on port 10111. Position, wind, and AIS data appear on the chart immediately.
macOS note Start at Login uses a LaunchAgent stored at ~/Library/LaunchAgents/com.sa3nmearelay.plist. On Windows it writes a value to HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

Language

The app supports English, Français, Deutsch, and Nederlands. The language selector is at the bottom of the left panel. Your choice is saved and restored on the next launch.

On first launch a pop-up asks you to choose a language before the main window opens.

Troubleshooting

Cannot connect to Sailaway

  • Confirm the NMEA Gateway is enabled in Sailaway's settings.
  • Check the host and port match what Sailaway is configured to use.
  • Make sure no firewall is blocking the connection on that port.

Navigation software shows no data

  • Confirm the TCP Relay is running (status line shows the port and client count).
  • Ensure your navigation app is configured to connect to 127.0.0.1 on port 10111 (or the port you configured).
  • Check the NMEA log window — if sentences are scrolling, the relay is receiving data.

Connection Lost pop-up appears repeatedly

  • This indicates Sailaway is closing the NMEA gateway connection. Check that Sailaway is running and the gateway is still enabled.
  • Enable Auto Connect so the app reconnects automatically after you restart Sailaway.

Dock icon does not disappear on macOS

  • Enable Menu Bar / Tray Only from the menu bar icon's context menu for permanent dock-less operation.
Log window The scrolling log in the main window shows every NMEA sentence received (green) and system messages (prefixed with #). This is useful for diagnosing connection or data issues.
